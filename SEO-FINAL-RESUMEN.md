## 🚀 Cómo Usar el Sistema SEO

### Para Agregar Nuevo Demo:

1. **Agregar metadata en `seo-config.ts`**:
```typescript
'demo-nuevo-servicio': {
  title: 'Tu Título SEO',
  description: 'Tu descripción de 150-160 caracteres',
  keywords: ['keyword1', 'keyword2', ...],
  ogImage: '/og-image-servicio.png',
  canonical: 'https://www.koptup.com/demo/nuevo-servicio',
}
```

2. **Crear layout.tsx**:
```typescript
import { generateMetadata, getBreadcrumbSchema } from '@/lib/seo-config';

export const metadata = generateMetadata('demo-nuevo-servicio');

export default function Layout({ children }) {
  const breadcrumb = getBreadcrumbSchema([
    { name: 'Inicio', url: '/' },
    { name: 'Demos', url: '/demo' },
    { name: 'Nuevo Servicio', url: '/demo/nuevo-servicio' },
  ]);

  return (
    <>
      <script type="application/ld+json" 
        dangerouslySetInnerHTML={{ __html: JSON.stringify(breadcrumb) }} />
      {children}
    </>
  );
}
```

3. **Actualizar sitemap.ts**:
```typescript
{
  url: `${baseUrl}/demo/nuevo-servicio`,
  lastModified: currentDate,
  changeFrequency: 'weekly',
  priority: 0.9,
}
```

¡Listo! El nuevo demo tendrá SEO completo automáticamente.
